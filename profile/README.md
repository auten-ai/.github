<h2 align="center">Give your AI agent hands</h2>

<p align="center">
  Auten lets Claude Code, Codex, Cursor or any MCP client click, type and read a real screen:
  your Mac, Windows or Linux computer and your Android phone (beta), even in apps that have no API.
</p>

- **Start here:** [auten-ai/auten-mcp](https://github.com/auten-ai/auten-mcp) — the MCP server, setup for every client, real screen capture
- **Add it to Claude Code:** `claude mcp add auten -- npx -y @autenai/mcp`
- **Or as a plugin:** `/plugin marketplace add auten-ai/auten-mcp` then `/plugin install auten@auten`
- **Questions:** [Discussions](https://github.com/auten-ai/auten-mcp/discussions) or [hello@auten.ai](mailto:hello@auten.ai)

Your agent does a task once, Auten can save it as a skill and replay it later without calling the model.
Passwords are typed locally and never reach the model.

Free plan: 30 min of runtime a month, no card. More on [auten.ai](https://auten.ai).
